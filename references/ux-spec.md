# UX-спецификация: «Командный центр входящих задач»

## 1. Структура экрана и порядок блоков

```
┌─────────────────────────────────────────────────────┐
│  ШАПКА: название + текущая дата                      │
├─────────────────────────────────────────────────────┤
│  ВЕРХНЯЯ ПАНЕЛЬ (KPI): 4 карточки-индикатора         │
│  [Всего] [Срочно] [Без данных] [Дубли]              │
├─────────────────────────────────────────────────────┤
│  ФИЛЬТРЫ И ПОИСК: строка + выпадающие списки        │
├──────────────────────┬──────────────────────────────┤
│  ЛЕВАЯ КОЛОНКА (60%) │  ПРАВАЯ КОЛОНКА (40%)        │
│                      │                              │
│  «Фокус дня»         │  «Нагрузка по команде»       │
│  ─────────────       │  ────────────────────        │
│  Список горящих      │  Карточки исполнителей       │
│  задач (высокий +    │  с количеством задач и       │
│  сегодня/завтра)     │  индикатором загрузки        │
│                      │                              │
│  «Все запросы»       │  «Возможные дубли»           │
│  ─────────────       │  ────────────────────        │
│  Карточки-строки     │  Группы дублей с             │
│  с фильтрацией       │  объяснением связи           │
│  и поиском           │                              │
│                      │  «Сводка для планёрки»       │
│                      │  ────────────────────        │
│                      │  Текст + кнопка копирования  │
└──────────────────────┴──────────────────────────────┘
```

Порядок блоков сверху вниз (в потоке скролла):

1. Шапка
2. Верхняя панель KPI
3. Фильтры и поиск
4. «Фокус дня» — левая колонка, верх
5. «Нагрузка по команде» — правая колонка, верх
6. «Все запросы» — левая колонка, низ
7. «Возможные дубли» — правая колонка, середина
8. «Сводка для планёрки» — правая колонка, низ

## 2. Показатели верхней панели (KPI)

Четыре карточки в ряд, каждая содержит:

| Карточка | Значение | Подпись | Цвет-акцент |
|----------|----------|---------|-------------|
| Всего запросов | 24 | «входящих задач» | нейтральный (серый) |
| Высокий приоритет | 9 | «срочно / блокируют» | красный |
| Требуют уточнения | 15 | «нет срока или ответственного» | оранжевый |
| Возможные дубли | 4 | «групп предположений» | фиолетовый |

Правила:
- Числа — крупный жирный шрифт; подпись — мелкий, серый.
- Карточки кликабельны: клик по «Высокий приоритет» фильтрует таблицу на высокий; клик по «Требуют уточнения» — показывает только задачи с пропусками; клик по «Дубли» — прокручивает к блоку дублей.
- При активном фильтре соответствующая карточка подсвечивается рамкой.

## 3. Правила блока «Фокус дня»

**Что показывается:**
Задачи с высоким приоритетом, у которых срок — сегодня или завтра.

**Порядок сортировки внутри блока:**
1. Сегодня (по времени: ближайший срок — первый).
2. Завтра (по времени).

**Формат карточки «Фокус дня»:**
```
[Номер] Краткое описание задачи
        Проект · Источник
        Ответственный: Имя / требует уточнения
        Срок: сегодня до HH:MM  ─── [высокий]
```

**Когда список пуст:** Показать сообщение «Нет горящих задач на сегодня и завтра» с иконкой зелёной галочки.

## 4. Способ показа нагрузки и возможных дублей

### 4.1 Нагрузка по команде

Блок в правой колонке, вертикальный список карточек исполнителей.

**Формат карточки исполнителя:**
```
Имя исполнителя
████████░░░  3 задачи (3 горящих)
Проекты: Орион
```

- Полоска загрузки: заполненная часть пропорциональна числу задач относительно максимального в команде (3).
- Цвет полоски: зелёный (1 задача), жёлтый (2), красный (3+).
- Под полоской — список проектов, к которым относятся задачи исполнителя (через запятую, не более 3).
- Исполнители сортируются по убыванию числа задач.
- Внизу блока — строка «Не назначено: N задач» (если есть), кликабельная — фильтрует таблицу на «нет ответственного».

### 4.2 Возможные дубли

Блок в правой колонке, под нагрузкой. Содержит группы дублей.

**Формат группы:**
```
Группа 1: Обновление КП «Орион»
  Запросы: 01, 07, 19
  Почему похоже: все три просят обновить коммерческое предложение 
  для клиента «Орион» (цены, этапы, сроки), но пришли из разных источников.
```

- Каждая группа — отдельный блок с серой рамкой.
- Номера запросов кликабельны — прокручивают к соответствующей карточке в таблице.
- Слово «Почему похоже» — обязательное пояснение на русском.
- Группы пронумерованы (1, 2, 3, 4).

## 5. Поиск и фильтры

### 5.1 Строка поиска

- Расположена над таблицей, занимает всю ширину колонки.
- Placeholder: «Поиск по тексту, проекту, исполнителю…»
- Поиск — мгновенный (поkeyup), без кнопки «Найти».
- Ищет по полям: текст запроса, номер, проект, ответственный, источник.
- Регистронезависимый, подстрока (includes).

### 5.2 Фильтры-выпадающие списки

Рядом со строкой поиска, горизонтально:

| Фильтр | Опции |
|--------|-------|
| Источник | Все, почта, рабочий чат, встреча, форма внутренних запросов, поручение руководителя |
| Проект | Все + уникальные значения проектов из 24 запросов |
| Приоритет | Все, Высокий, Средний, Низкий, Требует уточнения |
| Данные | Все, Полные, Требует уточнения |

- Значение по умолчанию — «Все».
- Фильтры работают комбинированные (AND).
- Каждый фильтр — `<select>` элемент.

### 5.3 Кнопка сброса

- Кнопка «Сбросить фильтры» расположена справа от фильтров.
- Видна только когда хотя бы один фильтр активен (не «Все») или в поиске есть текст.
- Сбрасывает все фильтры и поиск к значениям по умолчанию.

## 6. Пустое состояние и сброс фильтров

### Пустое состояние таблицы запросов

Когда ни одна задача не проходит текущий фильтр/поиск:

```
┌──────────────────────────────────────────┐
│  Ничего не найдено                       │
│  Попробуйте изменить фильтры или         │
│  сбросить параметры поиска.              │
│                          [Сбросить]      │
└──────────────────────────────────────────┘
```

- Текст по центру блока.
- Кнопка «Сбросить» — быстрый сброс всех фильтров и поиска.

### Пустое состояние «Фокус дня»

```
Нет горящих задач на сегодня и завтра.
Все под контролем.
```

## 7. Содержание сводки для планёрки и кнопка копирования

### 7.1 Блок «Сводка для планёрки»

Расположен в правой колонке, внизу. Содержит готовый текст:

```
Сводка на планёрку — [сегодняшняя дата]

Всего входящих запросов: 24
Высокий приоритет: 9
Требуют уточнения: 15 (нет срока или ответственного)

Фокус дня (сегодня/завтра):
— [Номер] Краткое описание · Ответственный · Срок
— ...

Нагрузка: Максим — 3 задачи (горящих), Павел — 2, Дарья — 2, Иван — 2.
Не назначены: 7 задач.

Возможные дубли:
1. Запросы 01, 07, 19 — обновление КП «Орион»
2. Запросы 02, 08 — проверка лендинга перед запуском рекламы
3. Запросы 12, 21 — UTM-метки на лендинге
4. Запросы 05, 11, 17 — согласование даты вебинара
```

### 7.2 Кнопка копирования

- Кнопка «Копировать сводку» — расположена под текстом сводки.
- При клике: копирует текст сводки в буфер обмена через `navigator.clipboard.writeText()`.
- После копирования: текст кнопки меняется на «Скопировано ✓» на 2 секунды, затем возвращается.
- Если буфер недоступен — fallback: выделяет текст сводки для ручного копирования.

## 8. Пользовательский путь

**Сценарий: координатор открывает приложение утром перед планёркой (цель — за 1 минуту).**

1. **Открывает страницу** → видит 4 KPI-карточки: общее число, срочные, проблемы данных, дубли. Сразу понимает масштаб.
2. **Смотрит «Фокус дня»** → видит список задач на сегодня и завтра с высоким приоритетом. Понимает, что горит.
3. **Бегло проверяет «Нагрузку»** → видит, что Максим перегружен (3 горящих). Понимает, кому нужна помощь.
4. **Просматривает «Дубли»** → видит 4 группы предположений. Понимает, что нужно проверить перед планёркой.
5. **Нажимает «Копировать сводку»** → получает готовый текст для руководителя.
6. **Если нужна конкретика** → фильтрует по проекту/исполнителю/источнику, находит нужные карточки.
7. **Если задача не найдена** → использует поиск.

## 9. Поведение на узком экране (мобильная адаптация)

**Брейкпоинт:** ≤ 768px.

Изменения:
1. **KPI-карточки:** из 4 в ряд → 2×2 сетка.
2. **Двухколоночная раскладка** → одна колонка. Порядок блоков: KPI → Фильтры → Фокус дня → Нагрузка → Дубли → Все запросы → Сводка.
3. **Фильтры:** выпадающие списки идут вертикально, каждый на всю ширину. Строка поиска — тоже на всю ширину.
4. **Карточки запросов:** уменьшается внутренний padding; описание может переноситься.
5. **Сводка:** блок растягивается на всю ширину; кнопка копирования — на всю ширину.

## 10. Критерии удобства первой версии

| # | Критерий | Как проверить |
|---|----------|---------------|
| 1 | Координатор видит число горящих задач за < 3 секунд после загрузки | KPI-карточки видны без скролла |
| 2 | Сводка для планёрки копируется одним кликом | Кнопка «Копировать сводку» на виду |
| 3 | Фильтры работают комбинированно и мгновенно | Выбор двух фильтров + ввод в поиск — результат обновляется сразу |
| 4 | Пустое состояние понятно и содержит кнопку сброса | Ввести несуществующий проект → видно сообщение + кнопку |
| 5 | Нагрузка видна без подсчёта вручную | Имя + полоска + число задач в одном блоке |
| 6 | Дубли объяснены, а не просто перечислены | У каждой группы есть «Почему похоже» |
| 7 | Текст сводки содержит все ключевые данные | Сводка = KPI + Фокус + Нагрузка + Дубли |
| 8 | Интерфейс читаем на экране 320px | Все элементы видны, текст не обрезан, кнопки кликабельны |
| 9 | Нет внешних зависимостей | Страница открывается как file:// или с любого статического сервера |
| 10 | 24 запроса на месте, номера сохранены | Каждый запрос от 01 до 24 виден в таблице |
