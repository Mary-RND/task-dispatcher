## Детали проверки

### Пункт 2 — 24 запроса
В `data.js` массив `requests` содержит объекты с id от `"01"` до `"24"` — ровно 24 записи.

### Пункт 3 — «требует уточнения»
- Запросы без ответственного (02, 05, 09, 14, 17, 18, 22) — `assignee: null`, отображаются как «требует уточнения».
- Запросы без срока (04, 10, 20, 24) — `deadline: null`, отображаются как «требует уточнения».
- Блок «Фокус дня» и сводка также используют «требует уточнения» для пустых значений.

### Пункт 4 — KPI-карточки
- Всего входящих задач: 24.
- Срочно / блокируют (высокий приоритет): 11.
- Нет срока или ответственного (проблемы данных): 11.
- Групп предположений (дубли): 4.

### Пункт 7 — объяснение дублей
Четыре группы дублей, каждая с описанием и причиной:
1. Запросы 01, 07, 19 — обновление КП «Орион» (один проект, один ответственный, один дедлайн, разные источники).
2. Запросы 02, 08 — проверка лендинга (одни и те же элементы, разные сроки и ответственные).
3. Запросы 12, 21 — UTM-метки (одна задача, один ответственный, разные сроки).
4. Запросы 05, 11, 17 — согласование даты вебинара (три этапа одного процесса).

### Пункт 8 — фильтры и поиск
- Поиск по тексту, ID, проекту, исполнителю, источнику.
- Фильтр по источнику (5 вариантов).
- Фильтр по проекту (11 вариантов).
- Фильтр по приоритету (высокий / средний / низкий).
- Фильтр по полноте данных (полные / требует уточнения).

### Пункт 9 — сброс и пустой результат
- Кнопка «Сбросить фильтры» появляется при активных фильтрах.
- При пустом результате отображается блок «Ничего не найдено» с подсказкой и кнопкой сброса.

### Пункт 10 — сводка и копирование

- Реализован clipboard API с fallback на `execCommand`.
